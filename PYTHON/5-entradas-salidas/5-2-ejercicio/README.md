Ejercicio práctico: "Recibo de compra"
Escribe un programa que:

Pida el nombre del cliente.
Pida el nombre de 3 productos y el precio de cada uno, y la cantidad que compra.
Calcule el subtotal, un IVA del 16 % y el total.
Imprima un recibo bien alineado, con 2 decimales, parecido a este:

```text

==============================
     RECIBO - Cliente: Ana
==============================
Producto        Cant.   Importe
Pan               2      $50.00
Leche             1      $28.50
Huevos            1      $65.00
------------------------------
Subtotal:               $143.50
IVA (16%):               $22.96
TOTAL:                  $166.46
==============================
```
