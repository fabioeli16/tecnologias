## Contenido

Por defecto, un programa se ejecuta línea por línea, de arriba hacia abajo. Las estructuras de control cambian ese orden. Hay dos grandes tipos:

Condicionales (if, elif, else, match): deciden qué código se ejecuta.
Bucles (while, for): deciden cuántas veces se ejecuta un bloque.
🔑 En Python, los bloques se definen por la indentación, que normalmente son 4 espacios. Todo lo que está indentado debajo de un if o de un for pertenece a ese bloque.

### Operadores

### Operadores de comparación

| Operador | Significado | Ejemplo | Resultado |
|---|---|---|---|
| `==` | igual a | `5 == 5` | `True` |
| `!=` | distinto de | `5 != 3` | `True` |
| `>` `<` | mayor / menor | `7 > 10` | `False` |
| `>=` `<=` | mayor / menor o igual | `4 <= 4` | `True` |
| `in` | está contenido en | `"a" in "casa"` | `True` |

### Operadores lógicos

| Operador | Es True cuando… | Ejemplo |
|---|---|---|
| `and` | ambas condiciones son verdaderas | `edad >= 18 and tiene_id` |
| `or` | al menos una es verdadera | `es_sabado or es_domingo` |
| `not` | invierte el valor | `not llueve` |



<!-- +++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++ -->
### Control en bucles

Control dentro de los bucles: break y continue
break: sale del bucle de inmediato.
continue: salta el resto de la vuelta actual y pasa a la siguiente.
