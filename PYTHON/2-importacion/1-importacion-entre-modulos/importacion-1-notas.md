## Descripcion

Este ejercicio se realizo con el proposito de entender la importacion.

En especifico la importacion de codigo entre modulos o archivos python. Es decir, un modulo usa las funciones o clases definidas en otro modulo.

Los modulos estaran en el mismo paquete.

Se realizo importacion en cadena

<!------------------------------------------------------------------------------------------------------------------------------------------------------->
## Ejecucion

Comando para entrar a la ruta del script (relativo al repositorio):
cd PYTHON\importacion\1-importacion-entre-modulos

Comando de windows y linux para ejecutar el script:
python main.py
